# MeUsMe

Uma coisa de cada vez. App pessoal para decidir o próximo passo e chegar ao fim do que começou.

## Ideias centrais

- **Agora**: o app escolhe *um* passo para você, de acordo com sua energia. Projeto em foco vence; depois, o projeto mais perto da linha de chegada.
- **Caixa**: tire da cabeça em 1 segundo (botão `+` ou `Ctrl+Espaço`). Organizar fica para depois.
- **Projetos**: todo projeto nasce com uma *linha de chegada*. Só o próximo passo fica visível.
- **Diário**: check-in de 30 segundos (humor, energia, uma frase).

Os dados ficam no próprio aparelho (localStorage). Sincronização entre dispositivos é o próximo passo.

## Rodar

```bash
npm install
npm run dev
```

Para abrir no celular, use o endereço "Network" que o Vite mostra (PC e celular na mesma rede Wi-Fi).
